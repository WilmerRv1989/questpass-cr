# QuestPass CR

Sitio web de QuestPass CR, una plataforma ficticia para reservar experiencias geek en Costa Rica: escape rooms, torneos retro, talleres, trivia y rol para principiantes.

Este repositorio corresponde al proyecto del curso SOFT-06-C2 Diseño y Programación Web de la Universidad CENFOTEC (2026-C3). En el primer avance construí la estructura del sitio con HTML semántico, CSS propio y Bootstrap 5, sin lógica de JavaScript.

## Integrante

- Wilmer Rodríguez Vega

## Páginas

- `index.html`: inicio.
- `experiencias.html`: las seis experiencias oficiales.
- `detalle.html`: información completa de la experiencia QST-001.
- `reservar.html`: formulario de reserva.
- `contacto.html`: formulario de contacto.
- `login.html`: formulario de inicio de sesión.
- `admin.html`: maqueta del panel de administración.

## Estructura de carpetas

```
questpass-cr/
  index.html
  experiencias.html
  detalle.html
  reservar.html
  contacto.html
  login.html
  admin.html
  css/
    bootstrap.min.css
    estilos.css
  js/
    bootstrap.bundle.min.js
  docs/
  README.md
```

- `css/estilos.css`: estilos propios.
- `docs/`: matriz de trazabilidad, mapa del sitio, wireframes y capturas.

## Cómo abrir el sitio

1. Descargar o clonar el repositorio.
2. Abrir `index.html` en cualquier navegador.

No requiere servidor ni conexión a internet: Bootstrap está incluido en el proyecto.
